Open File Explorer and find the USB
1
Plug the USB into the laptop
2
Press Windows key + E, or click the yellow folder on the taskbar. This opens File Explorer; you'll pick the USB next
3
In the left panel, click This PC, then the USB Drive (often D: or E:)
4
Double-click a folder to open it. Click the back arrow to go up a level
Shortcut: when you plug in the USB, Windows may pop up Open folder to view files. Click it to jump straight to the USB. Not every laptop shows it.

Windows basics · 5
Eject the USB safely
1
Close any File Explorer windows showing the USB
2
In File Explorer, right-click the USB Drive › Eject
3
Or: click the ^ arrow by the clock › USB icon › Eject
4
Wait for Safe to remove hardware, then pull the USB
Why it matters
Pulling the USB too soon can leave freshly copied files incomplete, and the controller upload may fail.
